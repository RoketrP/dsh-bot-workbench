# Changelog

## 0.1.0-rc.1 — 2026-11-09

First public release candidate for Harness 0.2.2-rc.1.

- Persistent native Bots, configurable responsibilities, capability references and optional model references.
- Private confirmed/candidate memory with editing, search, explicit sharing and forgetting.
- Evidence-bound acceptance, correction feedback, explicit handoffs and bounded task execution.
- Native daily/interval schedules, receipt visibility and separate execution/acceptance state.
- Interrupted-run reconciliation without automatic replay; stop-before-admission protection.
- Serialized Bot/workspace task admission and optimistic task edits.
- Full record export and inert, previewed template imports.
- Chinese/English UI, responsive layout, reproducible isolated native-package verification.

Development alpha packages were local test builds. The verification report identifies which versions were exercised in each environment.
