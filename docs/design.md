# 界面结构

按用户确认的“原生助手、简洁侧栏、Bot 卡片、对话优先”方向重做。

- 复用 Harness 已有侧栏，插件内只保留「我的助手 / 任务 / 计划」导航，避免再加一层侧栏。
- 首页直接选择助手并发消息，转入同一个长期原生会话。快捷建议只填入草稿，发送由用户触发。
- 助手卡片显示职责、状态与记忆入口；主助手提供默认对话对象。
- 记忆默认展示为文字。修改、共享和遗忘放入操作菜单；资料与管理分别使用标签。
- 任务列表保留标题、负责人和状态，详情放入侧边抽屉。交付结果、执行历史和设置分别展示。
- 验收仍要求逐项对照证据勾选，模型提交结果不等于用户接受。
- 每日与间隔计划只展示各自相关的字段。计划卡片显示时间、时区和真实宿主状态。
- 导入、导出、版本和诊断集中到数据与设置，首页不展示内部编号、配置树或调试信息。
- 使用宿主颜色和本机字体，浅色与深色跟随宿主；不下载字体、头像或增加遥测。
- 390px 宽度下改为单列助手卡片，抽屉铺满宽度；保留键盘关闭、焦点限制和减少动态效果选项。
