# 使用、数据与卸载

## 职责、能力与权限

Bot 创建时选择一个已有的原生能力预设，默认 standard。工作台登记一个独立预设引用，并通过公开接口注入职责与已确认记忆。工具、技能、模型连接和原生审批由宿主提供；职责文本不能额外授予权限。模型引用只包含 provider/model ID，没有密钥字段。

更新 Bot 职责、工作目录或模型前应结束当前工作并移除计划。新的配置会使用新的主会话，旧主会话留在原生历史中。创建时选定的能力预设不可在该 Bot 中直接替换；需要不同能力时创建新 Bot，再明确交接。

暂停 Bot 阻止工作台任务和该 Bot 后续原生步骤；当前执行需先停止。暂停任务保留原生计划并暂停未来触发，停止执行处理当前轮次。归档可恢复，不等于删除。

## 记忆

用户保存的记忆立即生效；模型提议和跨 Bot 共享形成候选，确认后才生效。每次提示最多注入最近 20 条已确认记忆。当前实现不提供向量检索。请保存简短稳定的偏好，不保存密码、密钥、验证码或完整支付信息。

遗忘删除当前记忆记录，后续不再注入；已发送给模型的上下文、原生会话、导出文件和备份不因此消失。修改记忆不会更改过去的会话。

## 计划与恢复

每日计划显式填写 IANA 时区；间隔至少 60 秒。原生计划中的 scheduledAt 由宿主管理。暂停后恢复使用下一次未来时间，不批量补跑。遵循宿主的夏令时语义：不存在的本地时间跳过，重复的本地时间选较早时刻。

原生投递只证明消息进入原生会话；任务领取才建立新的工作台运行记录。目标被修改、任务暂停、前次待验收或存在不确定运行时会拒绝领取。打开计划会话可查拒绝原因。计划领取前也可能消耗少量模型调用；工作台不会用自己的时钟替代宿主调度。

正常关闭插件会暂停它拥有的计划；重新启用时，仅恢复由插件关闭所暂停、且 Bot 和任务均未暂停或归档的计划。若希望重装后仍不运行，卸载前先主动暂停任务。强制进程退出时不能保证完成清理：重启后运行中的记录变为“需要核对”，不自动重放。暂停或停止不能撤销已经发生的外部变化。

“记录核对后的结果”仅记录用户核对说明；没有逐项证据时仍不能接受。可以关闭该轮，或要求修改后另行执行。

## 存储、导出和导入

数据使用公开 storageDomain 服务，域名 bot_workbench，per-record 布局，v1。逻辑表为 bots、memories、tasks、settings。JSON 后端的目录为当前 DSH_HOME 的 storages/bot_workbench；具体根目录由宿主管理。插件不直接改原生日志或其他 Bot 插件的数据。

导出 JSON 含 Bot 职责、私有记忆和完整任务历史，属于用户资料，应妥善保管。导入最大 2 MB，最多 100 个 Bot、2000 条记忆、500 项任务。导入先预览，检查所有目录和预设可用后建立新身份的副本；Bot 与任务均暂停，记忆为候选，不导入运行记录、会话、计划或验收权限。它是模板迁移，不是原生会话恢复器。完整导出历史仍可离线查阅。

导入逐条持久化，发生写入失败可能留下部分暂停副本；同一次导入可重试且不会重复创建已写入的身份。请在该导入窗口内重试；重新打开文件会产生新的导入身份。

rc.1 的记录格式对早期 alpha 增加了可选管理字段并在读取时补默认值。升级前先导出，并在 Host 停止时备份当前 profile 与本插件数据域。旧 alpha 不保证能读取 rc.1 写入的新字段；回退需同时恢复相应备份。不会自动迁移或覆盖其他插件的数据。

## 关闭和卸载

先在任务页停止当前工作并核对不确定结果，主动暂停不想恢复的计划，再到 Harness 插件页关闭或卸载本插件。默认保留数据。重装时可恢复原记录；原生会话依然按宿主规则保留。需要清除资料时先导出，通过记忆的“遗忘”清理相应记录；彻底清除域文件需在 Host 停止后由用户管理备份和数据目录。

## 限制与排错

- 同 Bot、同实际目录的工作台任务串行；不锁住其他插件、外部进程或普通会话。
- 无可用模型时检查 Harness 模型配置及 Bot 模型引用；不把密钥写入职责或记忆。
- 内容已变化时刷新后再操作，避免覆盖新状态。
- 原生计划已删除时移除旧关联后重建；目标发生改变时检查原计划和原会话。
- 原会话仍执行时先在原生界面停止，再核对结果。
- 证据引用是模型提出的文本，不保证存在或正确；工作台不自动打开未知链接。
- 兼容性仅限验证矩阵中的版本。没有 Windows 设备验证、云端托管保证或绝对金额上限。
